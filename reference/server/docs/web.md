# Web 工作区

Web 位于 `web/`，使用 React、TypeScript、Vite 和 ECharts，通过同源 `/api/v1` API 访问服务端。页面没有默认演示记录。

## 开发和构建

先设置 `MLBOARD_ROOT` 并加载工作区的 `scripts/env.sh`；依赖、缓存与构建产物均留在工作区。运行 `npm ci`、`npm test`、`npm run build`。Vite 开发代理默认指向 `127.0.0.1:8080`；生产服务用 `--web-dir` 指向 `web/dist`。构建会清理 dist，提交前恢复跟踪的空占位 `dist/.keep`，不提交产物或 node_modules。

## 导航与权限

应用侧栏可收起为图标栏，包含可搜索的组织切换、项目入口、组织成员/设置和账号入口。项目入口不展开项目列表；列表只显示本人明确有权限的项目。手机使用同一导航的抽屉。实例管理在独立区域。组织的项目权限目录用于添加或变更项目成员，不授予浏览实验数据的隐含权限。切换组织跳到对应项目列表；页面进入时同步所属组织，离开旧页面时不会覆盖主动选择。

图标栏悬停 450 ms 后显示名称提示，键盘聚焦时立即显示；移出、点击、失焦、滚动及 Escape 关闭。提示不接收指针、不抢占焦点，通过 aria-describedby 关联入口。组织设置、成员和项目权限目录仅使用全局导航，不再重复内侧栏；项目设置保留当前项目的局部导航和返回实验入口。

角色与权限由后端校验：普通已登录账号可以创建组织，创建后自动成为 owner。组织切换器和组织目录仅显示已加入的组织，实例管理员也必须先由组织管理者添加为成员才能访问该组织。组织 owner/admin 和已入组的实例管理员管理组织成员及项目授权；项目 owner/admin 管理本项目实验、成员、密钥和分享。项目 owner 的转交和最后所有者保护仍由服务端执行。

首次 `/setup` 收集实例名称、首个组织及管理员账号。`/register` 只在实例允许注册时提交真实注册 API；新账号没有自动组织或项目授权。实例资料、显示默认值、注册、分享、凭证期限和 OAuth 配置在 `/admin/settings` 保存，使用 revision/If-Match 防止覆盖。

实例 → 用户管理 → 创建邀请，必须填写预置用户名，邮箱可选；可选 1/7/30 天有效期，默认 7 天。生成后复制仅显示一次的注册链接。列表展示待注册、已注册、已过期、已撤销状态，待注册邀请可撤销。邀请可在关闭开放注册时使用；打开页面、反复访问和提交失败不会消耗，只有成功创建账号后失效。

受邀页固定显示预置用户名和邮箱，用户设置显示名称（可选）及密码并确认。已登录时先显示当前账号，用户可主动退出后继续注册。邀请密钥位于 URL fragment，仅在请求体提交；成功后替换导航清除链接。填有邮箱的本地账号可用用户名或邮箱和同一密码登录，邮箱忽略大小写。

## 实验文件夹和选择

项目首页可在卡片和列表之间切换，按用户保存本机偏好；两种视图共用搜索和授权项目集合。首次进入项目使用 `/overview`，之后从项目目录恢复当前账号在该项目最后打开的页签；显式 URL 始终按 URL 打开。概览先显示运行中、最近完成、最近失败各最多 3 条元数据，以及已保存视图；活动使用服务端 `sort=updated_at&order=desc` 独立排序，不把 ID 第一页当最近实验。某状态为空不代表整个项目为空，项目空入口仅依据总计数。视图根据当前账号在此浏览器的真实打开历史优先显示，历史只存最多 32 个 ID/时间，不伪称全账号使用排名。项目资料与一级文件夹收进折叠入口。预览不请求训练曲线。Charts 位于 `/charts`；原 `/workspace` 链接仍映射到同一图表页。实验侧栏只在 Charts 下方显示；项目头、页签、搜索/状态/参数条件和“已选 N”栏横跨完整内容区。选择对话框在各页签可用，筛选只改变候选列表，保留筛选外的明确选择。参数条件由服务端分页处理，不把已载入页面冒充全集。

概览预览、Charts 实验列表与整文件夹选择使用轻量元数据读取，不为导航计算全部训练历史摘要。Runs 的动态指标列、指标排序/CSV、对比和需要汇总字段的视图仍读取完整摘要；元数据与摘要选择缓存按模式隔离。显式引用实验 ID 的分析视图只读取这些实验，不再额外读取项目默认前 100 个实验。

Runs 表先展示已载入实验的路径、状态和时间，最多以 3 个并发请求补齐这些实验的精确摘要，优先当前可见页。读取期间可勾选、按路径/时间排序和翻页；所有已载入实验摘要完整后才启用指标排序与 CSV，不对部分摘要排序或导出。失败可局部重试；切页、项目、筛选或离开表格会取消当前摘要任务。摘要缓存按项目、Run ID 和实际 data revision 区分，并与轻元数据分开；读取中 revision 变化时采用服务端返回的完整新行。

Runs 的排序、页码和指标列配置与选集一同按账号/项目保存，切到 Charts/对比再返回仍保留。指标列可搜索选择最多 12 项，CSV 使用当前显示列；指标未齐全时排序/CSV 继续禁用。缺失或非有限指标始终排在末尾，不参与有限数值排名；排序只作用于已载入的集合，页面明确标注范围。

项目可按创建时间、更新时间、名称、Runs 数量升降序排列，排序字段和方向按用户保存在本机；默认按创建时间倒序。名称使用当前语言的自然排序，缺失的时间或数量始终排在末尾，排序不改变授权集合。搜索结果计数反映过滤后的项目数。卡片和列表同时显示创建、更新时间，窄屏改为分行而非隐藏；更新时间来自项目资料更新，不代表实验写入活动时间。

文件夹树按完整路径分段，展开后可进入子文件夹；三态勾选包含后代实验。整文件夹选择逐页解析成员，完成后一次性更新选集。取消、旧请求与错误不会应用部分结果。浏览器读取预算为 10,000 个实验、16 MiB、200 页；超限会明确报错并保留原选集。

实验选择侧栏只显示在项目图表工作区；Runs 表格、对比和项目其他页面使用完整内容区。桌面可拖动分隔线调宽（196–448 px，随可用宽度限制）、收起或恢复；分隔线支持方向键、Home/End、双击恢复默认宽度。宽度和收起状态按用户/项目保存在本机。拖动仅更新 CSS 变量与图表尺寸，保留图表实例。

桌面全局导航和实验侧栏统一使用向左收起、向右展开的双 chevron，普通状态为透明背景、无可见边框，悬停或键盘聚焦显示操作提示。控件方向参考 [Zabbix 官方侧栏实现](https://github.com/zabbix/zabbix/blob/05923e4c143ce6ddc232b54b0619ec3fa4460611/ui/app/partials/layout.htmlpage.aside.php#L32-L41)及[菜单说明](https://www.zabbix.com/documentation/current/en/manual/web_interface/menu)。实验侧栏收起后不保留空白列，仅在内容区边缘保留展开按钮；同一按钮保持焦点，展开恢复已保存宽度。手机继续使用独立抽屉入口。

选中集合独立于已载入的列表、搜索和分类筛选。Charts、Runs、对比共用按账号/项目保存的实验 ID、incarnation、路径、候选筛选和比较基准；清筛选不清明确选择，删除通知只移除对应实例。图表与对比每页最多 50 个；超过一页时保留完整选集并显示翻页控件。Runs 表格另有加载更多入口。保存要求完整选择与指标目录就绪、最多 50 个实验；不会把当前页冒充完整选集。

已加载的列表页共享项目订阅。数据变更只校准已载入 ID；创建、删除、状态/筛选成员变化和重连会沿新的游标有界重建已载入页链，保留选择和可见行锚点。隐藏或离开列表后暂停读取，返回时重新校准；失败保留已有元数据，显示局部重试。

分析视图逐查询解析固定集合和动态 selector，并与顶层 selection 取交集。固定 A 不会缩小另一个文件夹或全项目查询；显式空集合仍为空。无 query_refs 的 Run 来源投影仍解析顶层选集。固定保存绑定每个 Run 的 incarnation；旧实例被删除/重建时明确报错，不读取同 ID 的新实例。

高级定义中的 selector 暂不支持 summary:/ 字段（当前 Go resolver 未实现）。Web 明确报错，不用轻元数据的空 summary 算成无匹配。分页遇到过期/失效游标 410 时，在同一总字节预算内从第一页自动重建一次；再次失败保留已显示数据并提供重试。

## 图表

每张图右上角三点菜单提供数据检查器、查询 JSON/图像导出、缩放辅助操作、图表设置和全屏。常规卡片不显示展示点/记录数页脚。标题栏操作统一高度：桌面 32 px、手机 36 px，X 轴选择、编辑、放大和菜单垂直居中。放大按钮让图表在页面内占满一行并增高，还原后回到原布局；点击放大本身不提交修订，保存分析/更改时会保存该显示状态。原图表实例和缩放状态保留。

结构化记录选择独占一行，长 run 路径省略，Step 始终可见；视图/归一化/类别筛选放在下一行。下拉列表保留完整记录名称和上下文。

标量图各自使用 QuerySpec.x.field，工作区个人设置可以按图覆盖；编辑保存视图时更新该图查询。如果查询被其他面板复用，先复制查询，避免联动修改其他图。各指标可以有独立 step 数据；缺少坐标时显示无数据，不补 seq 或插值伪造坐标。共享光标仅在相同坐标语义间联动。

标量、ROC/PR、散点和二维嵌入图默认用鼠标左键拖动框选 X/Y 缩放，可以连续框选；普通点击和小幅抖动仍保留 hover。框选限制在实际绘图区内，反向拖动同样有效，对数轴按对数坐标缩放。`Alt+←` 撤销上次缩放，`0` 或双击复位；`Esc` 取消当前框选，之后仍可直接拖动。切换图表类型、X 轴或 Y 轴比例会清空缩放与历史。

触屏默认支持纵向滚动和点选提示。需要框选时，在图表三点菜单启用“触屏框选缩放”再拖动；完成一次框选、取消、撤销或复位后恢复滚动。第二根手指加入、指针取消、丢失捕获或窗口失焦时取消进行中的框选，不提交半成品范围。

页面级平滑、原始曲线、联动光标和分组方式收在工具栏的“显示设置”浮层中，浮层默认关闭；搜索及分区开合保持直接可用。保存面板的 `y_axis.scale`、`smoothing`（EMA alpha 为新观测权重）和 legend 会实际参与绘图。合并顺序为默认值、保存面板、明确的视图偏好、单图偏好；旧浏览器存下的默认值不覆盖面板声明。

“图表分组”的两种模式都只改变当前浏览器的展示，并按用户/视图保存偏好：

- **按分区**：依照保存视图的 `sections` 顺序与各面板的 `section_id` 显示，使用分区标题和默认折叠状态。未指定分区或引用不存在分区的面板进入“其他面板”。自动生成的项目/Run 视图本身已有按指标首级路径创建的分区，因此初始外观可能与另一模式相同。
- **按指标路径**：从每张面板全部 `query_refs` 的 `source.metrics[].name` 取得指标，按 `/` 切分后取前 1–4 段。深度 1 时，`train/loss/total` 和 `train/loss/aux` 都归 `train`；深度 2 都归 `train/loss`；深度 3 分别归 `train/loss/total`、`train/loss/aux`。较短路径保留全名，深度可以包含指标名本身；完全没有 `/` 的指标统一归“指标”。同一面板的全部指标得到同一个前缀时只放入该组；得到多个不同前缀时，整张面板放入“多指标”，不会拆图或重复展示。没有指标引用的面板（例如 Run 来源的散点图、没有绑定查询的 HTML）进入“其他面板”。分组按首次遇到的面板顺序出现，暂不采用保存分区的标题、归属和默认折叠状态。

指标分组只依据指标名称，不依据 Run 文件夹、上下文或图表标题；切回“按分区”恢复原分区展示。切换本身不提交 DashboardSpec，明确保存时才写入视图。

每张时序图的独立设置菜单可覆盖平滑、原始曲线、图例、线性/对数 Y 轴和提示排序。覆盖是个人浏览偏好，不改写保存视图的声明。底部图例直接点击可多选曲线，以色块与高亮文字标记已显示项，不使用勾选框；旁边的重置按钮恢复全部曲线。点击绘图区中的曲线可单独查看，再次点击恢复。PNG 导出当前绘图区；数据检查器提供查询结果和 CSV。

实验配色按当前账号、项目保存在本浏览器。当前比较集合优先使用 12 色预设；不足时从扩展候选中按 OKLab 距离选择与已显示颜色最远的颜色。已显示曲线保持颜色，新增实验尽量避开相近色；排序、分页、实时数据更新不重新分配。大集合无法保证每条曲线肉眼可区分，未参与比较的候选实验使用确定性回退色。同一实验的不同指标/context 共用颜色。

点击图例色点可选择预设、HEX 或系统选色器；点击名称仍控制曲线显隐。手动颜色优先，可用“恢复自动颜色”重新分配；自动色对当前浅色/深色图表背景保持至少 3:1 对比度，自定义色按输入原样使用。改色同步本项目的其他图表、侧栏、选择栏和比较表，只更新绘制、不重读训练数据。颜色是个人浏览偏好，不写入 Run、保存方案或分享定义，也不随账号同步到其他设备。

私有图表只显示自动更新状态与暂停/继续操作。暂停冻结当前页面已确认的数据，不控制训练，不写入视图；暂停时仍可缩放和重置。标量图框选保留具体横轴范围，新数据延长全范围后仍保持该区间，每图标题栏的圆形箭头或工具栏重置可恢复完整范围。进行中的框选使用已绘制的坐标，期间只保留一份最新待绘制结果，手势结束后提交。

同一项目共用一条 typed SSE 订阅，250 ms 合并通知、刷新启动至少间隔 500 ms。可见面板按 revision 只保留一个在途读取和一个最新水位，慢请求后直接追最新状态；不同选择/坐标的旧 generation 不写入新图。折叠、不可见、隐藏页面和暂停期间取消读取，恢复后校准最新水位。已确认数据在失败/断线时保留，局部提示尚未更新。这里仍使用有界完整 query，未声称实现服务端 delta 或持久 tiles。

纯 data_changed 不再使所有选择/指标目录失效：已载入列表按 changed ID 校准，未载入的所选实验和已保存视图仅在 ID 相交时合并刷新；series 目录随对应 Run revision 更新。缓存失效会分离旧在途任务，新读不复用它；旧消费者仍可完成自己的读，但旧结果不能重新写入已失效缓存，注销也会取消这些分离任务。

显示设置支持自动排列、卡片最小宽度（240–960 px，默认 360）、高度（240–800 px，默认 320）、数值格式（自动/小数/科学计数法）和 0–10 位小数。按实际内容区宽度自动换行，窄屏最大宽度受容器限制；布局变化仅调整已有图表尺寸。自动生成的项目/Run 图表默认自动排列，保存视图默认使用声明布局；编辑保存视图时按声明位置编辑，自动排列不改写 DashboardSpec。页面设置与平滑/联动偏好按用户和视图保存，公开分享仍使用安全的偏好范围。

每张卡片可拖动右下角调整宽高，左右边调整宽度、底边调整高度；方向键微调 16 px，Shift 为 64 px，Escape 取消。拖动时邻卡保持位置，松手后按阅读顺序换行，行分页按实际卡片宽度计算；卡片尺寸不会触发已有曲线的重新查询。全屏和临时放大时不显示拖拽手柄。菜单“恢复默认卡片尺寸”恢复当前显示设置/布局尺寸。

单卡尺寸按账号/视图保存在当前浏览器，“保存分析方案”或保存已编辑方案时写入 `view.presentation.panels[id].size`（整数 CSS px，width 240–1600，height 240–1000）。height 是基础卡片高度，展开图例会额外增加阅读空间。窄屏只收窄显示，不改写已保存宽度；共享定义的尺寸更新后采用新定义。单卡尺寸优先于基础网格布局；明确修改编辑器的布局宽高或使用 `resize_panel` 时会清除该卡片的单独尺寸。图例的紧凑/展开状态共用同一列宽和名称换行规则，仅改变阅读高度。

数值格式影响数值刻度及图表提示：自动格式会对极小非零值和大值使用科学计数法；X 刻度省略不必要的末尾零，hover 的实际记录坐标保持原文。数据查询、原始值、检查器与导出不因显示精度而取整。缺失和非有限值继续显示为空。

hover 使用紧凑表格，显示曲线颜色、原始值、EMA 和各曲线的实际采样坐标，根据视口高度最多展示 12 行并标明剩余数量。没有采样记录的值显示为空，不把缺失值当零或虚构插值。浮层避开视口边缘且完全穿透鼠标、触摸和滚轮事件，不阻挡继续移动、框选或页面滚动；完整记录在数据检查器中查看。联动图表只联动光标，浮层只在当前图表显示。

框选查询与分页有总行数/字节预算；折叠动画结束后卸载面板，不可见图表按需释放。图表分区初次按保存状态静态展示；后续开合期间保留已显示图表，暂停新面板的可见性判定，布局稳定后再按实际视口加载，避免压缩中的分区临时进入视口而创建离屏图表。主题、语言和全屏变化保留 ECharts 实例。文件夹、分区、菜单和手机抽屉支持开合过渡，路由仅对现有容器应用短暂淡入，不通过 key 重新挂载图表；reduced-motion 下禁用动画并立即按视口加载。

私有页面共用持久的应用外框和内部懒加载边界；项目与 Run 页签只让切换的内容区执行 180 ms 淡入和 2 px 位移，页头和页签不参与父级过渡。项目设置、账号、组织和实例管理同样只动画表单、列表等内容块，页头、面包屑、局部导航及顶层弹窗保持静止；设置内容区统一限宽，不随当前是否有表单改变父容器宽度。导航活动指示条平滑移动，页签选中状态使用相同字重，项目 Runs 计数始终显示项目总数，避免切换页签时导航尺寸变化。根滚动条保留占位，长短内容切换不改变页面可用宽度。项目卡片/列表的切换动画只在改变展示方式时执行，初次进入由统一路由动画处理。快速切换会取消旧过渡，普通数据刷新不触发路由动画；reduced-motion 下跳过动画。项目页脚在短页面位于视口底部，长页面位于内容末尾，保留手机安全区。

路由过渡由统一控制器执行，避免与旧页面 CSS 入场重复叠加。同一导航内的活动背景平滑移动；进入或退出实例管理时重置位置，导航仅淡入，不在不同菜单间长距离滑动。项目设置的内侧栏随列宽展开，内部页签切换不重复展开。reduced-motion 下跳过这些过渡。

全局导航的活动背景左右边界直接使用导航容器当前内边距，收起、展开及快速反转时同步跟随侧栏宽度，不对每帧宽度测量再次执行缓动；切换菜单项保留纵向滑动。图标提示仍使用浏览器顶层浮层，不受导航滚动区域裁剪。

界面使用 14 px 主文字/导航，12–13 px 次要文字，避免小于 12 px 的功能文本；导航图标 20 px，普通按钮图标 17 px。通过缩减卡片内边距、列表行距和导航分隔收紧布局，手机保留至少 36 px 的主要控件高度。概览根据实际内容容器宽度决定单双列，收起侧栏后会利用释放的空间。

## 表单与分享

项目内“连接 Python SDK”连续完成项目密钥签发、验证示例和首数据确认。训练预设请求 runs/data 的读写 scope，只读分析仅请求读；自定义权限与完整密钥设置在高级入口。权限不足时不自动升级。密钥只保留在当前弹窗内，关闭后不持久保存。示例绑定项目与组织 ID，使用唯一验证路径；页面只在该路径的已提交 data_revision 大于零后显示收到数据，只读示例不会显示上传成功。

Charts 的“保存分析”在当前页面收集名称、固定/动态范围、个人/项目可见性。保存从查询定义与当前真实显示偏好序列化，不从已下载 frame 反推：每图坐标、平滑、图例、布局、折叠、分组、面板过滤、数值格式和提示偏好写入版本化 view.presentation。固定范围保存 incarnation pins；动态范围保留筛选条件。保存成功可继续分析或打开新视图。

已保存视图中的显示调整和布局编辑共用冻结 editBase。SSE 的 remoteHead 不能推进本地草稿的 If-Match；新修订和 412 均保留草稿，可查看新版本、明确放弃或另存个人副本。布局/显示调整在标题行预留位置标记，暂停不产生调整标记。保存权限优先使用服务端 can_edit；个人视图由其所有者编辑，项目共享使用项目写权限。JSON、XML、历史与 Agent 保留在高级菜单，Agent 也绑定同一条件版本基线。

对比使用完整 exact summary 的 last/min/max，可选择基准及各指标的优化方向。差值为候选减基准，百分比除以基准绝对值；零/缺失/非有限基准显示“—”。未声明方向时不显示最佳排名。

## 账号关注

全局“关注”与 Charts 侧栏、Runs 表格、Run 详情的星标接入当前账号的 following API。关注独立于比较选择和通知订阅。列表按可见卡片懒读最多两个精确指标及一条有界真实趋势；趋势保留坐标间距和非有限/gap 边界，不生成演示数据。

每个 Run+incarnation 的待同步操作记录最终目标 bool，串行发送 PUT/DELETE 并携带 If-Match。失败保留待同步意图，412 必须显式重试并重取版本；重连不自动覆盖另一端。取消关注有撤销入口。账号切换隔离并取消旧任务，注销清除其持久待同步项，旧响应和撤销回调不能再写。用户私有流同时处理 following_changed、personal dashboard_changed 和 reset；个人视图 ID 不进入项目流。

成功的关注写响应会合并重读列表，即使 SSE 暂断也能更新关注页；列表接受远端状态本身不会触发循环读取。尚未同步或已确认但列表尚待刷新时显示等待状态，不误报为从未关注。

API scope 使用 fieldset/legend 和独立 checkbox label，长 scope 在网格内换行；弹窗内容滚动而操作区保持可见，支持 Escape、焦点约束与关闭后的焦点恢复。项目工作区通过同页“项目成员 / 免登录链接”对话框分享，默认固定当前明确选择及其 incarnation，不能静默扩大到全项目。设置中的链接管理仍允许输入已知 Run ID，由服务端校验归属。两处复用相同表单和服务端预览，不使用原生 datalist 弹层。

创建分享先调用服务端“分享内容预览”，仅显示按拟定公开权限剔除后的项目、实验和可选参数，不使用页面已有私有对象冒充公开结果。默认不计算指标汇总，用户逐个读取；超时、系列数或源记录预算不足在对应实验内明确提示，不显示伪造空值。媒体选项只显示是否授予访问，不读取文件内容。预览不生成可访问链接；发布与后续匿名访问仍独立复核权限，数据可继续更新。修改表单会取消在途请求并使预览失效，没有当前成功预览时不能发布。发布携带服务端返回的 Run ID/incarnation pins 和有效期，重建同名实验会被拒绝，空项目也不会悄悄加入未来实验。

下拉控件使用统一的可搜索首字母/键盘导航列表，保留原生表单的值、校验和 change 事件。浮层使用浏览器顶层 Popover，支持嵌套在弹窗或全屏图表中；Escape 从最上层逐级关闭，点击或聚焦外部关闭。现代浏览器需支持 Popover、inert 和 ResizeObserver。

## 查询编辑与实时更新

修改标题、尺寸或分区会完整保留多指标、多查询引用和未编辑的 source/transform；只编辑第一个指标时保留后续指标。共享查询只在其内容改变时复制。删除或解绑面板会回收无引用查询，仍有面板引用的查询保留；读取旧视图时，无引用查询也不会触发额外实验读取。

Web 与 Go 使用 `contracts/run-selector-cases.json` 验证分类、路径深度和 JSON Pointer 的共同语义。两项分类字段都省略表示不限分类；显式空分类选择返回零项，只有 `include_ungrouped:true` 且无 prefix 时只选择根级实验。

项目 SSE 暂时断网或 5xx 后按 1–30 秒退避重连，权限探测最多等待 10 秒；只有明确 401/403/404/410 才停止重连。成功连接重置退避并合并刷新。切换项目、隐藏页面和卸载会关闭流、取消探测及刷新/重连 timer，旧探测结果不会改变新连接。
