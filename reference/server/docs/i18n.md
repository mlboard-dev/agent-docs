# 国际化与主题

## 消息

`web/src/i18n.ts` 提供 `t(message, params)` 和 `useI18n()`。源消息作为中文词典的 key，`locales/zh.ts` 提供中文词典，`locales/en.ts` 提供英文翻译。React 组件通过 `useI18n()` 订阅语言变化；普通格式化/查询帮助函数使用同一语言状态。

可见文案在源码显式调用翻译函数，不遍历或替换 DOM。插值使用命名参数，例如 `t("已选 {count} 个实验", { count })`。插入值保持为 React 文本，翻译函数不解析 HTML。项目、组织和 run 名称、用户文本、指标、上下文、JSON、协议字段与 API scope 不自动翻译。

添加文案时同时添加英文词典条目。`i18n.test.ts` 检查所有页面和组件的字面消息覆盖及中英文插值一致，验证日期、数值格式化。纯界面描述使用 `formatDate`/`formatNumber` 或显式 locale；工具提示中的原始坐标和指标值保留精确原文。

## 偏好和默认值

语言为中文/English，主题为 system/light/dark。偏好只保存 locale/theme 到本地 `mlboard:appearance:v1`；无浏览器存储时仍可在内存切换。用户未保存偏好时，`/auth/status` 的实例默认值在显示登录和私有页面前生效；已有用户偏好优先。

登录后的语言入口位于账号 → 个人资料；主题入口是头像旁的图标菜单，可选浅色、深色或跟随系统。登录、首次设置和公开分享保留独立的外观控件。

`index.html` 在模块前阻塞加载同源 `public/appearance.js`，兼容服务端 `script-src self` CSP；该同步 bootstrap 在 React 和样式加载前应用保存的主题/语言；未指定主题时读取系统深色偏好。系统变化和多标签页 storage 事件会更新当前外观。第一次访问在 auth/status 返回前使用 system 加载背景；静态 HTML 不包含实例配置。Bootstrap 和 React 偏好解析都有无效存储回归。

所有页面、表单、弹窗、公开分享、提示和 HTML 容器使用 CSS 语义颜色变量。ECharts 单独更新文字、网格、tooltip、热图等配色，并保留实例和缩放状态。隔离 HTML 作者自己绘制的内容仍由该文档控制，父页面仅保证容器随主题变化。
