# Web v3.1 正式工作流

设计基线是根仓库 `docs/design/experiment-workflow-v3/README.md`、`app.js`、`styles.css` 及 `live-and-following.md`。本轮更改正式 `web/`，保留真实 API、选择身份、编辑基线及所有面板类型。

| 设计要求 | 正式实现 |
| --- | --- |
| 组织与项目分层 | 全局组织选择只切组织；项目组织 crumb 返回该组织的项目目录。项目列表首次进入概览，之后恢复按账号/项目记录的页签。 |
| 完整项目头 → tabs → 共享筛选/选择 | `ProjectWorkspaceHeader` 与稳定选择栏横跨内容区，仅 Charts 下方显示实验侧栏。桌面项目页不再保留空组织顶条，账号/主题/全局侧栏收起控制位于全局侧栏底部；管理与设置保留各自导航。 |
| 同选集 | Charts/Runs/Compare 共用明确 ID/incarnation 集合、搜索、状态、参数条件、表格偏好和基准。筛选不取消选择；选择对话框的全选明确限定“已载入”，文件夹选择沿用有界完整读取。 |
| 参数筛选 | `GET /projects/{id}/runs?filters=<JSON数组>`，与状态/路径/搜索组合，由服务端分页。提供 model/lr 快捷条件与任意 `config:/` JSON Pointer，保留文本/数字/布尔/JSON 类型。最多 50 条、16 KiB；不支持的 summary 字段明确拒绝。`run_scan` 预算错误提示缩小范围，不宣称全量索引检索。 |
| 首屏活动 | 三个状态各自读取真正 `updated_at desc` 最近元数据，失败与空态互不清空；常用视图基于真实本机访问记录排序，资料次级折叠。只有总数为零时显示接入引导。 |
| 接入实验 | 顶栏连续三步真实项目密钥 → 可运行示例 → 首数据探测；不模拟 ACK，不自动提权。 |
| 当前页保存 | 统一由顶栏“保存视图”打开 fixed/dynamic 与 personal/project 单选说明，移除旧页尾重复入口。固定保存完整当前选择的身份；动态保留完整 selector，条件为空时明说覆盖项目当前/未来实验。保存坐标/平滑/分组/布局等定义，不保存下载帧或暂停状态。 |
| 保存视图与协作 | 保存视图继续显示项目头与 tabs，视图修订/范围单独呈现；编辑/JSON/XML/历史/Agent 位于高级菜单。`can_edit`、冻结 editBase、If-Match、remoteHead 和另存副本沿用原逻辑。 |
| 同页分享 | “项目成员”使用真实成员 API；“免登录链接”先服务端预览再发布。项目默认固定当前选择，空/超过 50/身份未就绪不会回退全项目；保存视图分享固化当前实际 resolved union，动态条件不会公开未来实验。 |
| 披露投影 | 新表单显式提交 `include_metrics` 和 `config_fields` 白名单，默认不含配置/媒体。服务端预览、真实发布、链接列表与匿名页统一展示有效权限。metrics=false 不挂载公开图表；config_fields 的 nil（旧全量）和 []（无字段）语义不混用。媒体独立权限保留在高级范围。 |
| 实时、关注与稳定布局 | 自动更新/暂停固定尺寸，暂停不改选择、不写视图、不复位轴范围。单图 reset 与菜单桌面同 28px、手机同 36px。关注复用账号 API，与比较选择独立。局部错误保留内容并可重试。 |

`filters` 列表契约与披露字段需要配套服务端版本；前端不对忽略未知参数的旧端宣称筛选已经生效。新披露契约在 schema 13 提供，旧链接按服务端默认值兼容，受限新链接的回滚保护由服务端执行。

浏览器语义仍使用产品路由，不移植设计稿的“手机模拟器”。项目页签内容各自恢复滚动；异步行/面板加载时等待可恢复位置，用户开始操作后停止恢复。SSE 重读使用实际滚动容器保持列表锚点。

## 验证范围

实施分块运行严格 TypeScript（含 noUnused）、Web 单元测试与生产构建。新增验证覆盖明确分享范围/身份与披露策略、未包含指标时不显示汇总入口、账号/项目页签隔离，以及参数类型、JSON Pointer、null/缺失、条件预算、URL/存储与动态保存语义。

真实浏览器由主代理统一验收，子任务没有并行操作浏览器。这里不将单元测试称为视觉/触屏或跨设备验收，也不据此新增服务端性能结论。建议真实验收顺序：组织目录 → 项目接入/概览 → Runs 选择与参数筛选 → Charts 调整 → 比较 → 同页保存/重开 → 内外分享/匿名访问 → 冲突 → 手机与主题/语言。关注和原生 iOS 验证仍分别按账号 API 与原生工程记录。
